# Computer Programming

## Unit 4: Control Flow, Boolean Logic, and Iteration

In this unit, students learn how to control the flow of a Java program using conditional statements and loops. They explore how programs make decisions based on Boolean expressions and how combining conditions allows programs to handle increasingly complex situations.

Students begin with `if` statements and expand to `if-else` and `if-else-if` structures. They learn to use Boolean expressions to determine which sections of code execute, including combining conditions with `&&` (AND), `||` (OR), and `!` (NOT). Students also explore nested conditionals and practice tracing program execution to understand how decisions affect a program's behavior.

The unit explores Boolean algebra, including De Morgan's laws and short-circuit evaluation. Students learn how to simplify and reason about logical expressions while understanding how Java evaluates compound conditions.

Students then apply Boolean logic to repetition. They learn to use `while` loops and `for` loops to execute code repeatedly, understanding loop initialization, conditions, updates, and termination. They practice tracing loops, identifying common errors, and determining how many times a loop executes.

Finally, students are introduced to recursion as an alternative approach to repetition. They explore how methods can call themselves, the importance of base cases and recursive cases, and how recursive calls contribute to solving a problem.

By the end of this unit, students should be able to write and analyze Java programs that make decisions, combine logical conditions, repeat operations using loops, and solve problems using recursion.

### Topics

1. **If Statements**
2. **If-Else Statements**
3. **If-Else-If Statements**
4. **Boolean Expressions**
   - Evaluating expressions that produce `true` or `false`.
5. **Boolean Operators (`&&`, `||`, `!`)**
   - Combining and negating Boolean expressions using AND, OR, and NOT.
6. **Nested If Statements**
7. **Boolean Algebra**
   - Simplifying and manipulating logical expressions.
8. **De Morgan's Laws**
   - Rewriting Boolean expressions by negating and swapping AND/OR operators.
9. **Control Flow**
   - Tracing the order in which statements execute as a program makes decisions.
10. **Short-Circuit Evaluation**
    - Understanding how Java skips evaluating the second operand of `&&` or `||` when the result is already determined.
11. **While Loops**
12. **For Loops**
13. **Loop Tracing**
    - Determining how many times a loop executes and how variable values change during iteration.
14. **Nested Loops**
15. **Recursion**
    - Understanding how methods call themselves to solve problems.
16. **Base Cases and Recursive Cases**
    - Identifying when recursion stops and how each recursive call moves toward that stopping point.
